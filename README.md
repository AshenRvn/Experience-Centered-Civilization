## 中文

### 关于本项目

如果不再需要劳动，你可以成为任何人。

这是一个思想实验，一份开源的文明设计草案。它的前提是：AGI 已替代所有人类劳动。它要回答的核心问题是——**当人不再需要工作，为什么而活**。

回答的方式不是道德呼吁，而是一套完整的文明框架设计，包括：

- **五条核心原则**——AI 工具性、人类最终主权、体验替代劳动、文明不能灭、全凭自愿
- **三层架构**——地表（物理层）、元宇宙层（入口层）、沙盒（体验层）
- **意义循环系统**——通过记忆处理与欲望重置，在无限时间尺度上持续再生意义
- **AI 分类体系**——现实 AI、虚拟 AI、内层 AI（硅基人类）、虚拟议会 AI，严格分离权力
- **三层治理架构**——日常层（AI 自动化）、重大层（全体人类直接民主）、终极层（文明存续底线契约）

它坦诚承认自己的边界，不宣称真理，不要求权力。它是一个邀请，不是一个命令。

## English

### About This Project

> If labor is no longer necessary, you can become anyone.

This is a thought experiment — an open-source blueprint for civilization. It begins from a single premise: **AGI has replaced all human labor**. The core question it seeks to answer: **What does one live for when work is no longer necessary?**

The answer is not a moral appeal, but a complete civilizational framework, including:

- **Five Core Principles** — AI-as-tool, ultimate human sovereignty, experience replacing labor, civilization must not perish, total voluntariness
- **Three-Layer Architecture** — The Surface (physical layer), the Metaverse Layer (entry layer), Sandboxes (experience layer)
- **The Meaning Cycle** — Continuous regeneration of meaning across infinite timescales through memory processing and desire reset
- **AI Classification System** — Reality AI, Virtual AI, Inner-Layer AI (silicon humans), Virtual Parliament AI, with strictly separated powers
- **Three-Tier Governance** — Daily tier (AI automation), Major tier (direct democracy by all humans), Ultimate tier (Civilization Survival Baseline Compact)

It honestly acknowledges its own boundaries, claims no truth, and demands no power. It is an invitation, not a command.
